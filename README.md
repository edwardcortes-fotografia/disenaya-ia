# DiseñaYa IA V4.1

Primer esqueleto de aplicación real con Next.js.

## Ejecutar
1. Instala Node.js.
2. En esta carpeta ejecuta `npm install`.
3. Ejecuta `npm run dev`.
4. Abre `http://localhost:3000`.

## Qué funciona
- Interfaz React/Next.js.
- Crear una campaña.
- Generación local simulada.
- Vista previa.
- Guardado en memoria durante la sesión.
